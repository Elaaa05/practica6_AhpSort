# Práctica 6 - AHPSort II (criminalidad por provincias)

Un único script, `practica6.py`, resuelve los 4 ejercicios.

    pip install numpy pandas matplotlib openpyxl geopandas

Los datos (Excel y shapefiles) están en `data/`.
